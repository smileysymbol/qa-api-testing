# Тестирование Google Maps API, Chuck Norris API, Star Wars API
Практические примеры тестирования REST API на Python с использованием `requests`.

## Содержание
- **chuck_norris_categories.py** - тестирование получения шуток по всем категориям
- **chuck_norris_specific.py** - тестирование с выбором конкретной категории
- **google_maps_post_get.py** - создание и чтение локаций (POST + GET)
- **google_maps_delete.py** - создание, удаление и валидация локаций (POST + DELETE + GET)
- **starwars_characters.py** - работа с SWAPI для получения связанных данных

## Технологии
- Python 3
- Библиотека `requests`

## Установка зависимостей
pip install -r requirements.txt

## Запуск
Каждый файл независимый. Запустить можно через:
- Кнопку **Run** в PyCharm
- Терминал: `python имя_файла.py`
